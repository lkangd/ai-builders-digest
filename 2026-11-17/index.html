"When you ask Claude to create something, it's operating in a fresh context where it thinks: Oh my God, the user asked me to make an app. I'm going to invent the most brilliant visual style."

From @nateparrott at Anthropic on how to get Claude to avoid the same designs:

"It's going to be serif text, an off-white background, orange, and these bars on the edges of the cards. Because in Claude's mind, it's only ever done this once, so it thinks this is totally original.

Vercel CEO Guillermo Rauch launched xeet, a hermetic, pixel-perfect X post renderer written in safe Rust and WASM. It uses no browser, network, filesystem, or system fonts, and can render a post to PNG in about a millisecond (0.4 ms for Jack’s first tweet). He says that is 100x–1000x faster than opening Chrome for a screenshot, while still reproducing Blink and HarfBuzz shaping, fine-grained line breaking, RTL, Chirp font subsets, and CJK/emoji fallbacks. xeet is structured as an “autorepo”: an oracle boots Chrome to check tens of thousands of layout rules, and a CI canary watches the live product and opens signed PRs for agents. He also joked that models are getting good at naming, after a slowdown-diagnosis CLI came back as hog.
译文
Vercel CEO Guillermo Rauch 发布了 xeet：用安全的 Rust 和 WASM 实现的封闭式、像素级准确 X 帖子渲染器。它不依赖浏览器、网络、文件系统或系统字体，大约 1 毫秒即可把帖子渲成 PNG（Jack 的第一条推文约 0.4 毫秒）。他称这比启动 Chrome 截图快 100 到 1000 倍，同时复现 Blink 与 HarfBuzz 排版、精细断行、RTL、28 套 Chirp 字体子集以及 CJK/数学/Emoji 回退。xeet 被做成 autorepo：一个 oracle 启动 Chrome 核对数万条排版规则，CI canary 跟踪原产品变化并提交带签名的 PR 供 agent 处理。他还提到模型越来越会起名，自己做的系统卡顿诊断 CLI 被命名为 hog。

A hermetic, pixel-perfect X post renderer in safe Rust / wasm. Zero browser, network, filesystem, system fonts. Renders a post to PNG in ~1ms (and 0.4 ms for @jack's "setting up my twttr" 😁).

X is the global town square, and the medium is the message. Being able to preview what things will look like before posting is great for both humans and agents.

Rendering with xeet is is 100x-1000x faster than booting up a browser and taking a screenshot, yet it's just as accurate.

It reproduces Blink & HarfBuzz text shaping, 1/64px line breaking, RTL bidi, 28 Chirp font subsets, CJK/Math/Emoji fallbacks, "Show more" rules, etc. It's the kind of thing that would be wildly impractical, if not impossible, for a human engineer to pull off.

A CI canary then watches the evolution of the original, and files signed PRs for agents to act on. It was conceived from the ground up around 'verification engineering', and the result speaks for itself.
