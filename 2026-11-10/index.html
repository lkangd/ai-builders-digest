Built a physical simulation of a record player with WebGL2 and Web Audio. It's *shockingly* accurate: http://vinyl-gl.vercel.app.

Instead of playing a song, it works by converting it into the physical shape of a groove. Then a simulated stylus rides those walls 384,000 times a second, and you hear the voltage that motion would induce in a cartridge.

So the crackle, the pops, the wow/flutter, the dull inner grooves are natural byproducts of the simulation. You can also "DJ" the record.

(The converted songs are in the public domain or CC-licensed. Code is linked for you to remix and re-deploy.)
译文
我用 WebGL2 和 Web Audio 做了一个唱片机的物理模拟。它准确得*令人震惊*：http://vinyl-gl.vercel.app。

它不是直接播放歌曲，而是把歌曲转换成纹槽的物理形状。然后，模拟唱针每秒 384,000 次沿槽壁运动，你听到的是这种运动在唱头中感应出的电压。

因此，噼啪声、爆音、抖晃、内侧纹槽发闷，都是模拟的自然副产物。你还可以对唱片“打碟”。

We’re moving from an era of AI where the output comes roughly at the rate that you can chat back and forth with the AI to work with you, to a period where you can set a problem for a set of agents to go off and do an arbitrarily large amount of work for you. This means productivity gains that are maybe 20-50% to gains that don’t really have an upper limit.

Agent swarms and the ability to fan out complex work across many agents doing tasks in parallel provide a massive unlock in a lot of spaces. This will lead to qualitatively different outcomes in my fields.

This has already been seen across the coding domain. Next, cyber is almost entirely a problem space where more agents reviewing more things will lead to far better outcomes. We’re seeing the same now in many scientific fields, and this almost certainly will change life sciences.

But this will increasingly be true in any field where you can parallelize computer-based work to complete something faster or do something at a totally different quality level. Which is actually are some of the most valuable domains of knowledge work today.

Our brains aren’t really wired for the new scenario we’re heading into where compute becomes the variable that we can flex to solve any problem that we want. We’re used to thinking that the amount of time that goes into a task is correlated to the output that we get from it. And most domains of knowledge work or science have generally always been correlated with this. That’s changing forever.
译文
我们正从 AI 产出速度大致取决于你能与 AI 来回聊天协作的时代，迈向可以给一组智能体设定问题、让它们为你完成任意规模工作的时期。这意味着生产力提升从大约 20–50% 到几乎没有上限。

智能体集群，以及把复杂工作分发给许多并行执行任务的智能体的能力，将在许多领域带来巨大释放。这将在我所在领域带来质变结果。

编码领域已经出现这种情况。接下来，网络安全几乎完全是一个问题空间：更多智能体审查更多内容会带来好得多的结果。许多科学领域现在也在出现同样情况，这几乎肯定会改变生命科学。

但任何能并行化基于计算机的工作、更快完成某事或达到完全不同质量水平的领域，都会越来越如此。而这些实际上是当今知识工作中最有价值的一些领域。

我们的大脑并未真正适应即将进入的新场景：算力成为可灵活调配以解决任何问题的变量。我们习惯认为投入任务的时间与产出相关。大多数知识工作或科学领域一直以来也普遍如此。但这正在永久改变。

A good lesson in AI is that you need to check back in on the latest with every 3 to 6 months to try something that wasn’t possible before and see if it works again.

At no point in AI’s history is that more true than today. Just the past six months of model progress around computer and tool use, less context rot, better reasoning, multimodality, and deeper domain expertise in a number of key fields, these models are vastly more capable on what they can execute.

This is opening up a new vector of what AI systems will be able to autonomously work on. Essentially, anything with an API (and even many things without), we can anticipate that an agent will be able to control and utilize as an underlying capability to complete a process.

This means that we are no longer dependent on *just* the models generating everything from whole cloth, but instead they can fully utilize existing systems (or new ones purpose built for them) very effectively. This creates immense leverage for agents.

Security agents can leverage existing data feeds and cyber tooling, IT agents that can execute workflows reliably across software stacks, data agents that can migrate data or processes between systems, architect and design agents can leverage CAD and design tools, and on and on. And any of today’s tools that don’t work will likely be replaced by agent-friendly or OSS tooling that does the same.

When you combine this with the domain understanding being trained into agents, you started to get autonomous collaborators for every job function and industry. This will open up a ton of new opportunities in AI if you build with this understanding in mind.
译文
AI 的一条好经验是，每 3 到 6 个月就要重新了解最新进展，尝试以前不可能的事，看看现在是否可行。

AI 历史上没有哪个时刻比今天更适用。仅过去六个月，模型在计算机与工具使用、减少上下文腐化、更强推理、多模态以及若干关键领域更深专业知识方面的进展，使其可执行能力大幅提升。

这开辟了 AI 系统可自主工作的新方向。基本上，任何有 API 的东西（甚至许多没有 API 的），我们都可以预期智能体能够控制并利用它作为完成流程的底层能力。

这意味着我们不再*只*依赖模型从零生成一切，而是它们能非常有效地充分利用现有系统（或为其专门构建的新系统）。这为智能体创造了巨大杠杆。

安全智能体可利用现有数据源和网络工具；IT 智能体可在软件栈间可靠执行工作流；数据智能体可在系统间迁移数据或流程；架构与设计智能体可利用 CAD 和设计工具；如此等等。今天任何不好用的工具，很可能被同样功能的智能体友好或 OSS 工具取代。

当这与训练进智能体的领域理解相结合，你就会开始为每个岗位职能和行业获得自主协作者。如果带着这种理解去构建，这将在 AI 中开启大量新机会。
